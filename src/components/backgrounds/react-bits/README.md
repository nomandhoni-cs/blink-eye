# React Bits background components

These TypeScript/CSS components are ported from React Bits and used under the included MIT + Commons Clause license. Their official light/dark preview artwork is included as picker thumbnails.

- [Acid Squares](https://reactbits.dev/c/backgrounds/acid-squares)
- [Antigravity](https://reactbits.dev/c/backgrounds/antigravity)
- [Balatro](https://reactbits.dev/c/backgrounds/balatro)
- [Ballpit](https://reactbits.dev/c/backgrounds/ballpit)
- [CRT Warp](https://reactbits.dev/c/backgrounds/crt-warp)
- [Dark Veil](https://reactbits.dev/c/backgrounds/dark-veil)
- [Dither](https://reactbits.dev/c/backgrounds/dither)
- [Dot Grid](https://reactbits.dev/c/backgrounds/dot-grid)
- [Faulty Terminal](https://reactbits.dev/c/backgrounds/faulty-terminal)
- [Ferrofluid](https://reactbits.dev/c/backgrounds/ferrofluid)
- [Floating Lines](https://reactbits.dev/c/backgrounds/floating-lines)
- [Galaxy](https://reactbits.dev/c/backgrounds/galaxy)
- [Iridescence](https://reactbits.dev/c/backgrounds/iridescence)

The components are bundled as part of Blink Eye, not distributed as a standalone component package. Their upstream license is in `LICENSE.md`.
